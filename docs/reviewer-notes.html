PHP Simple Check — notes for reviewers

Single-purpose, fully local extension. Nothing is transmitted off the device.

What it does

After a page loads, the extension inspects signals that are already available to that page — response headers (one same-origin HEAD request), cookies the page's own JavaScript can read, URLs and markup — and shows a verdict: 🔴 PHP usage detected, 🟡 possibly PHP, or 🟢 no PHP signals. The verdict appears on the toolbar icon, an optional on-page badge and in the popup, which also lists every signal that contributed to the score.

How to test (2 minutes)

  1. Install the extension and open any https:// page. A badge appears in the bottom-right corner and the toolbar icon takes a colour.
  2. Click the badge (or the toolbar icon) to see the breakdown: score, signals, observed headers.
  3. For a clear 🔴, open https://wordpress.org/ (WordPress runs on PHP). For a clear 🟢, open https://example.com/.
  4. Use Rescan to re-run the check and Copy report to copy the English fingerprint to the clipboard.

Network behaviour

The only request the extension makes is a HEAD request to the URL you already opened, issued from that page's own origin, to read its response headers. It is visible in DevTools › Network. There are no servers, no analytics and no remote code; all translations and assets are bundled.

Permissions

Declared permissionWhy
storage Remembers the on-page badge preference and per-site "hide" choices; keeps the latest verdict per tab in session storage so the popup can show it (cleared when the tab closes).
Content script on http(s) pages The verdict concerns whichever page the user opens. On that page it reads the page's own DOM, issues the one HEAD request described above, and appends a badge element. It has no host_permissions, no cookie API access, and no network interception. The Chrome Web Store is excluded via exclude_matches.

What it is not

It is a stack fingerprint, not a malware or security scanner. "Uses PHP" is not a risk rating, and the extension never blocks, redirects or modifies a navigation.
